# The "*Zonomic Bible*"

Principles we use for building all our software.

1. Design
    - Design first, then write code
    - Don't overcomplicate. Sometimes all you need is something really simple.
    - Make it *fully* free and opensource
    - Use existing tools and formats (like `JSON` or `markdown`), only make your own if it is really necessary
    - Make it simple, slice it into various components

2. Write
    - Make the dependencies and build instructions as simple as possible
    - Write a *clear* `README`.
        - What is the project, documentation link
        - How do setup/install (if it's too large, link it to `/DOC/Setup.md`)
        - Contributing
        - License
    - Include a `DOC/` folder documenting the project
        - Setup/install
        - About/Project History
        - Contribution Guide
    - Do *NOT* document the application's source code API (there probably are tools that do this for you, like `godoc` for Golang)

3. Branding
    - Use Inkscape/Pixelorama
    - Logo
    - Banner

4. Share
    - Make a video demonstrating the project (Use Kdenlive, [Manim](https://manim.community) and OBS Studio)
    - Share on forums/discord servers
