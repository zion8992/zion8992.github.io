# The "*Zonomic Bible*"

The principles needed for building Zonomic apps

1. Design
    - Design first, then write code
    - Don't overcomplicate. Sometimes all you need is something really simple.
    - Make it *fully* free and opensource
    - Use existing formats (like `JSON` or `Markdown`), only make your own if it is really necessary
    - Make it simple, slice it into various components

2. Write
    - Make the toolchain (dependencies and build instructions) as simple as possible
    - Write a *clear* `README`. (say whether or not you accept PRs)
    - Include a `DOC/` folder documenting the project
    - Do *NOT* document the applications API

3. Branding
    - Use Inkscape/Pixelorama to make a logo

4. Share
    - Make a video demonstrating the project (Use Kdenlive, [Manim](https://manim.community) and OBS Studio)
